从需求到交付，决定留在聊天里。

  1. 一起收集角色与动作

    黑色马尾、白色紧身运动长裤、健美操。明确采用 20–25 岁成年女性设定，保存 8 秒原地循环动作。

  2. 生成第一版角色

    校验需求、披露 Tripo 积分使用，经用户同意后生成。打开精确版本，让用户检查外观。

  3. 反馈驱动外观迭代

    “身材再纤细一点，面容再美丽一点。”创建第二版，重新取得付费授权，原版保留。

  4. 自动运行免费绑定测试

    用户接受第二版外观后，选定该版本并运行本地 RigTest，检查模型加载和动画时间推进。

  5. 生成已保存的健美操

    披露绑定风险，经用户同时接受绑定结果、授权指定 SayMotion 请求后立即生成，不再重复询问动作需求。

  6. 对照预览与文件交付

    显示源动作和适配结果。交付角色、动作、源动作、清单与报告，校验大小和 SHA-256。交付不等于验收。

一次具体反馈，一份保留原版的迭代。
