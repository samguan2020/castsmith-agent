Turn natural language into

From brief to delivery, decisions stay in chat.

  1. Capture character and motion together

    A black ponytail, white athletic leggings and aerobics. Establish an adult woman aged 20–25 and save an eight-second, in-place looping motion.

  2. Generate the first character

    Validate the brief, disclose potential Tripo credit use and generate after consent. Open the exact version for appearance review.

  3. Iterate on specific feedback

    “Make her figure a little slimmer and her face more beautiful.” Create a second candidate with fresh paid consent, preserving the original.

  4. Run the free binding test automatically

    After appearance acceptance, select that version and run local RigTest. Verify model readiness and advancing animation time.

  5. Generate the saved aerobics request

    Disclose binding risks, obtain binding acceptance and authorization for the exact SayMotion request, then start without asking for unchanged requirements again.

  6. Compare and deliver

    Show source and adapted motion. Deliver the character, motion, source, manifests and report, checking sizes and SHA-256 hashes. Delivery is not acceptance.

One agent. Seven skills. One execution engine.

CastSmith is a single-agent system, not a team of independent agents. Skills guide the workflow; tools perform concrete operations.

03 / State & presentation

Local assets, read-only previews and delivery

The engine persists build records and artifacts in the workspace. The local viewer shows the character, RigTest, and synchronized source/adapted motion. Reviews stay in chat.

Host file, terminal and browser tools support request validation, preview verification and delivery. The local delivery command checks saved files and copies exact-version GLBs, manifests and quality reports into a fresh export folder.

How the workflow runs

Understand the request, load a skill, validate inputs and inspect saved state, then call the appropriate tool. Appearance acceptance unlocks the free RigTest. Binding acceptance and explicit SayMotion permission precede motion generation. Results return to chat for review, iteration and asset delivery.

Generation calls are synchronous; skills are workflow guidance, not independent background workers. Explore the project README →

Assistant

04 / Disclose risks and authorize this exact motion

Assistant
